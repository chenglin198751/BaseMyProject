# 小猫快玩

**1、代码：**
1. 代码地址：https://v.src.corp.qihoo.net/zhushou_android/zhushou
2. qbuild打包地址：https://qbuild.corp.qihoo.net/android/index.php/ShadowTasks/index?task_id=21438&project_id=228
3. 插件分支：develop_xmkw（plugins目录存放插件）
4. 主程分支：master_xmkw

	
**2、插件说明：**
1. 主页列表：模块化——modulation；gradlew :plugins:modulation:app:assembleRelease
2. h5：webview
3. 主页的tab：home_page
4. app_info：AppInfoActivity是评论详情页，AppInfoBottomView详情页底部
comment_normal_list_item是评论item布局；把app_info打包成recommend.jar（gradlew :plugins:app_info:app:assembleRelease）
5. 桌面快捷方式引导：PluginInstrumentationImp
6. search：打包成com.qihoo360.mobilesafe.search.jar ，gradlew :plugins:search:app:assembleRelease
7. D:\AndroidCode\master_xmkw\app\src\main\assets\conf文件，打开server=t就是测试环境，关闭线上环境
8. RecommendFragment是home_page的首页推荐页面；MultiTabHomePage是首页的两个Tab实现；HomeTabAdapter是首页具体的ViewPager fragment adapter实现；RecommendRecView是首页推荐的
9. 跨插件打开Activity：
   Intent intent = new Intent(); intent.setClassName("com.qihoo.appstore.appinfopage.gameappinfo",AppInfoActivityProxy.APP_INFO_VIDEO_ACTIVITY_CLASS_NAME);
   intent.putExtras(bundle);
   context.startActivity(intent);
   
   
   val intent = Intent()
   intent.putExtra(KEY_APP_INFO, appInfo)
   intent.putExtra(KEY_CHECK_VPN_GAME, checkVpnGame)
   intent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK)
   intent.putExtra(KEY_BUSINESS_PKG, isBusinessPkg)
   intent.putExtra(KEY_IS_FROM_QUICK_DOWNLOAD, isFromQuickDownload)
   intent.setExtrasClassLoader(AppInfo::class.java.classLoader)
   RePlugin.startActivity(
       context,
       intent,
       PluginConfigInfo.PLUGIN_MODULATION,
       "com.qihoo.plugin.modulation.activity.MagicDownloadStartActivity"
   )   
   
10. 卡片ContainerDef 全部模板信息：ContainerItem910000首页推荐的卡片点击，ContainerItem910100
11. QuickDownloadHelper#saveQuickDownload，设置好归因之后，会通过action_recommend_changed来通知首页刷新
刷新方法：BaseModulateView#loadData(0)
首页列表的展示数据：ModulationRepo#getModular，具体关注t is TemplateCard9100条件下的逻辑
归因游戏打开时会调用SPUtils.setLongSetting(QuickDownloadHelper.KEY_FIRST_QUICK_APP_INFO_TIME_MILLIS, 0)
saveQuickDownload apkResInfo = 归因是否撞成功，看这个日志
12. CommentReplyDialog是回复评论对话框；CommentListFragment是评论列表页
13. app沙箱中转页：MagicDownloadStartActivity；启动沙箱的类：DockerExecuteService
