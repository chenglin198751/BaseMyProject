# 小猫快玩

**1、代码：**
1. 代码地址：https://v.src.corp.qihoo.net/zhushou_android/zhushou
2. qbuild打包地址：https://qbuild.corp.qihoo.net/android/index.php/ShadowTasks/index?task_id=21438&project_id=228
3. 插件分支：develop_xmkw（plugins目录存放插件）
4. 主程分支：master_xmkw

	
**2、插件说明：**
1. 主页列表：模块化——modulation
2. h5：webview
3. 主页的tab：home_page
4. app_info：AppInfoActivity是评论详情页，comment_normal_list_item是评论item布局；开发时，需要先把\plugins\app_info\app\proguard-rules.pro中的recommend_590提高版本号，然后再提高plugins\app_info\app\build.gradle中版本号。最后把app_info打包成recommend.jar（gradlew :plugins:app_info:app:assembleRelease）
5. 桌面快捷方式引导：DockerShortcutGuideActivity   MainActivityImpl.handleDockOpen()
6. search：打包成com.qihoo360.mobilesafe.search.jar ，gradlew :plugins:search:app:assembleRelease
