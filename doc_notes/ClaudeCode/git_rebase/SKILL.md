# 更新当前分支

1. 检查当前分支、工作区和 Git 操作状态。处于 detached HEAD、工作区不干净或已有操作未完成时，停止并说明；不自动 stash。
2. 确认当前分支已配置上游；没有上游时停止并询问，不猜测远程分支。
3. 执行 `git pull --rebase`。遇到冲突按下方规则处理；其他失败时，若 rebase 尚未结束则执行 `git rebase --abort`，并说明原因。
4. 遇到冲突时，结合上下文保留双方合理改动，解决后 `git add`，再执行 `git rebase --continue`；重复处理后续冲突。变基时 `HEAD` 一侧是上游，另一侧是正在重放的本地提交。
5. 删除冲突或空提交不能直接假定取舍：确认意图后再处理；无法确定时记录冲突信息，执行 `git rebase --abort` 并说明原因。
6. 成功后报告当前分支、上游和冲突处理结果。只在本地完成，不自动 push；涉及已推送的提交被重写时提醒用户。
