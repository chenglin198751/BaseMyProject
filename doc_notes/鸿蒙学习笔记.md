**4、可选参数：**

	1.可选参数的格式可为name?: Type
	function hello(name?: string) {
	  if (name == undefined) {
		console.log('Hello!');
	  } else {
		console.log(`Hello, ${name}!`);
	  }
	}
	
	2.可选参数的另一种形式为设置的参数默认值。如果在函数调用中这个参数被省略了，则会使用此参数的默认值作为实参。
	function multiply(n: number, coeff: number = 2): number {
	  return n * coeff;
	}
	multiply(2);  // 返回2*2
	multiply(2, 3); // 返回2*3	
	
**5、箭头函数（Lambda函数）可嵌套在别的正常函数内部：**	

	let sum = (x: number, y: number): number => {
	  return x + y;
	}
	
**6、接口可以继承：**	

	interface Style {

**7、function和method不一样：**

	在ArkTS中，function关键字定义的函数可以被定义在类的外部，但不能直接定义在类的内部。
	function myFunction() {
		console.log("");
	}

	class MyClass {
		// 类内部的方法
		myMethod() {
			console.log("");
		}
	}

	const instance = new MyClass();
	instance.myMethod();
	myFunction();


**8、空安全和判空检查：**		

	1.默认情况下，ArkTS中的所有类型都是不可为空的。但是可以为空值的变量定义为联合类型T | null。
	let x: number | null = null;
	
	2.关于在访问对象属性时判空的3种运算符：
	class Person  {
	  nick: string | null = null;
	}

	function foo(person: Person  | null) {
	  // 1.（官方名字：非空断言运算符）如果运行时a为空，则发生运行时异常
	  person!.nick;
	  
	  // 2.（官方名字：可选链运算符）如果运行时a为空，或者a.value为空，则可选链运算符会返回undefined
	  person?.nick
	  
	  // 3.（官方名字：空值合并运算符）a ?? b等价于三元运算符(a != null && a != undefined) ? a : b
	  person.nick ?? ''
	}
