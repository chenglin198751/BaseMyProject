**7、function和method不一样：**

**8、空安全和判空检查：**		
1. 默认情况下，ArkTS中的所有类型都是不可为空的。但是可以为空值的变量定义为联合类型T | null。
	let x: number | null = null;
	@State param: ParamsType | null = null;
	
2. 关于在访问对象属性时判空的3种运算符：
	class Person  {
	  nick: string | null = null;
	}

	function foo(person: Person  | null) {
	  // 1.（官方名字：非空断言运算符）如果运行时a为空，则发生运行时异常
	  person!.nick;
	  
	  // 2.（官方名字：可选链运算符）如果运行时a为空，或者a.value为空，则可选链运算符会返回undefined
	  person?.nick
	  
	  // 3.（官方名字：空值合并运算符）a ?? b等价于三元运算符(a != null && a != undefined) ? a : b
	  person.nick ?? ''
	}

**10、应用状态管理-数据共享：**	
- AppStorage是应用全局的UI状态存储
- LocalStorage是页面级的，通常应用于页面内的数据共享
- PersistentStorage是持久化的数据
- 以上这些数据是通过业务逻辑中实现，与UI解耦，如果希望这些数据在UI中使用，需要用到@StorageProp和@StorageLink。

**11、装饰器：**
- @Watch应用于对状态变量的监听。如果开发者需要关注某个状态变量的值是否改变，可以使用@Watch为状态变量设置回调函数。
- $$运算符为系统内置组件提供TS变量的引用，使得TS变量和系统内置组件的内部状态保持同步
- @Prop装饰器：父向子单向同步
- @Link装饰器：父子双向同步
- @Provide装饰器和@Consume装饰器：与后代组件双向同步，变量名必须一样。

**12、component声明周期：**

	// 页面每次显示时触发一次，包括路由过程、应用进入前台等场景。
	// 只有被@Entry装饰的组件才可以调用页面的生命周期
	onPageShow() {
	}
	
	// 页面每次隐藏时触发一次，包括路由过程、应用进入后台等场景。
	// 只有被@Entry装饰的组件才可以调用页面的生命周期
	onPageHide() {
	}

	// 当用户点击返回按钮时触发。
	// 只有被@Entry装饰的组件才可以调用页面的生命周期
	onBackPress() {
	  // 返回true表示页面自己处理返回逻辑，不进行页面路由；
	  // 返回false表示使用默认的路由返回逻辑，不设置返回值按照false处理
	  return true 
	}

	// 组件即将出现时回调该接口，具体时机为在创建自定义组件的新实例后，在执行其build()函数之前执行。

	}

	// 组件build()函数执行完成之后回调该接口，不建议在onDidBuild函数中更改状态变量、
	// 使用animateTo等功能，这可能会导致不稳定的UI表现。
	onDidBuild() {
	}

	// aboutToDisappear函数在自定义组件析构销毁之前执行。不允许在aboutToDisappear函数中改变状态变量，
	// 特别是@Link变量的修改可能会导致应用程序行为不稳定。
	aboutToDisappear() {
	}
